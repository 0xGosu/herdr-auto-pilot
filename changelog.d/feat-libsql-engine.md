- Added the `libsql` database engine (`[database] engine = "libsql"`): share one hap store across machines through any libsql server — Turso Cloud, a hosted provider such as Layerbase, or your own `sqld` — over Hrana (HTTP). Set it up with `database.libsql_url` and `database.libsql_auth_token` (or `LIBSQL_AUTH_TOKEN`). It keeps no local copy, so every store call is a round trip to the server: pick a nearby one. The daemon warns at start when the server is far.
- Added `hap migrate --to libsql` and `hap migrate --to sqlite --from libsql`. The libsql engine never imports your local database on its own; run the migration with the daemon stopped.
- The `turso` engine is unchanged: same keys, same local replica. Use it with Turso Cloud; use `libsql` for servers that do not speak Turso's sync protocol.
