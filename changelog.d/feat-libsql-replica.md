- Added the `libsql_replica` database engine. It keeps the store in a local replica and syncs it with any libsql server, including a self-hosted `sqld`: local changes are pushed a couple of seconds after each write, and other nodes' changes are pulled on the poll interval. Reads stay on the machine, writes keep working while the server is unreachable, and it can share one database with nodes on the plain `libsql` engine.
